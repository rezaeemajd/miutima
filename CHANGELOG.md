# Changelog

## v1.0.0 — Stable Foundation

Initial stable release of miutima.

### Included

- Interactive terminal downloader
- MP4 video download
- MP3 audio extraction
- Video quality selection
- Playlist support
- Estimated size before download
- Rich progress interface
- FFmpeg integration
- Network and fragment retries
- Continued/resumable downloads
- Windows, Linux and Termux-compatible Python implementation

### Not included in v1.0.0

The following were added in later development and are intentionally absent from this historical snapshot:

- YouTube search
- Clipboard integration
- Download history
- Persistent settings
- Smart Downloader menu
